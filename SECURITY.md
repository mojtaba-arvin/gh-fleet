# Security Policy

## Supported versions

Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature in the repository's **Security** tab. Include affected versions, impact, and steps to reproduce. The maintainer will coordinate a fix and disclosure.

`gh-fleet` reads credentials from the GitHub CLI at runtime. Do not attach cache files, terminal logs, credentials, or private repository data to a report.
